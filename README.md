# Slate

A simple tool to manage your PDFs and web links.

## Features

- **Manage Links**: Save your favorite websites for quick access.
- **View PDFs**: Open and read PDFs directly in the app.

## Built With

- **Visual Studio**
- **MSVC**
- **wxWidgets (v3.3.1)**
- **wxPDFViewer**
- **SQLite3**
- **Internet Explorer**

## How to Run

1. Download the latest release zip file from the **Releases** section.
2. Extract the zip file.
3. Run the `slate.exe` file. 🎉
