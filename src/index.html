Welcome to Slate

A simple tool to manage your PDFs and web links.

What is Slate?

Slate is a project I've been working on to help organize web links and view PDFs easily. This is just a personal project to learn wxWidgets and other technologies.

Here are some of the key things it can do:

  • Manage Links: Save your favorite websites for quick access.
  • View PDFs: Open and read PDFs directly in the app.
  • SQLite3 Database: Keeps everything stored locally for quick retrieval.

Limitations

As this is is just a personal project there are many things I have to implement

  • Internet Explorer Backend: It can't render modern web pages (I will work on this).
  • Manual Path Setup: You have to manually set up the paths to the website (I know, not great).
  • Multitab: There is no multiple tab support(I will work on this later)
  • Text Selection: You can't select the text in the pdf :( (Actually wxPDFViewer didn't implement it. So...)

Created by M.H.Jim

Built with the following technologies:

Visual Studio, wxWidgets (v3.3.1), wxPDFViewer, SQLite3, and a little help from Internet Explorer.
